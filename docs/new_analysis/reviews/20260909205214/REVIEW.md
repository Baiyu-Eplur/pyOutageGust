## 一、先说明评价的客观标准

### 1. 标准的来源及优先级

第一层是用户原实验设计：完整取得独立于事件发生的天气；保持区域日标签不变；比较全部八个任务的新旧参数、Brier 和校准；只有预测表现有实质改善、校准明显改善且没有数据质量反证，才考虑进入正文。无改善、变差或技术不可行时不勉强转正；证据不明确时保留判断。

第二层是**运行前已经写入代码并保存在 experiment.json 的候选量化门槛**：八任务平均相对 Brier 改善至少 5%，LAD 配对 bootstrap 的 95% 区间下界大于 0，没有单任务退化超过 5%，分箱校准 RMSE 平均相对改善至少 5%。平均 Brier 改善小于 1% 被实现视为微小变化。这些是本实验的事前操作规则，不是通用统计标准，也不等于正式预注册；本审查不因看到结果而改变门槛。

第三层是解释结果必须满足的有效性条件：数据可追溯、计算可复核、模型没有明显退化、图形有足够样本支持、结论与验证所能支持的范围一致。**文件生成成功、优化器 success=true、图上的点接近对角线，单独都不是转正证据。**

### 2. 指标定义和判定规则

设某阈值下第 i 个区域日的标签为 yᵢ∈{0,1}，折外预测概率为 pᵢ：

- **Brier score**：BS = mean[(pᵢ−yᵢ)²]，越低越好。
- **相对改善**：G = (BS旧−BS新)/BS旧；G>0 表示新版本更好。本报告的“改善 %”为 100G，不能与概率的百分点混用。
- **总体指标**：八个 G 的等权平均，不是先平均两个版本的 Brier 再求比值；必须同时查看每个阈值，避免总体值掩盖不利结果。
- **分箱校准 RMSE**：sqrt[Σ_b n_b(p̄_b−ȳ_b)²/N]，越低越好。须检查箱样本量、分箱边界与图形，不把单点/单事件视为稳定频率。
- **区间**：固定本次折外预测，按 LAD 对新旧误差配对抽样 1,000 次的百分位区间。它不是重新训练后全部不确定性的区间，也未覆盖共享风暴/日期的全部依赖。

Brier 同时反映校准与区分能力，不能直接称为“纯校准误差”；接近常数的预测可能校准良好却几乎没有区分能力。这也是同时检查 Brier 和校准图的原因。[概率校准与评分规则说明](https://scikit-learn.org/stable/modules/calibration.html)

还有明确的展示限制：图中八个连向“观测频率=1”的最右端点，每个箱都只有 **1 个区域日、1 个事件**；其中七个属于新网格曲线，一个属于旧 wthr_gt1000。它们拉长纵轴，使主要概率区被压缩，并形成视觉上很陡的线段。真实的单次观察没有错，但不能据此判断稳定校准或高阵风预测质量。原图没有标箱人数或不确定性，现状不足以支持“明显更贴近对角线”的论文表述。

### 8. 自动判定：保守拦截有效，但原因不够完整

decision.json 返回 intermediate，理由是“存在未收敛拟合”。这是因为实现先检查任意一次拟合失败，再检查负的平均 Brier 改善。因此它没有误报转正，但该状态**不代表结果接近通过，也不只是‘改进略微但还不确定’**。

更完整的人工判定应同时说明：数据取得成功；八任务没有达到预测改善门槛；最稀有组存在全样本及折内退化；校准展示不支持总体明显改善。单独引用自动报告的一句话会漏掉后面三项。

## 四、方法局限与必须避免的结论

1. **旧代理带有事件选择性。** 它的锚点来自当天发生事件的位置。LAD 留出模型参数并没有重建一个完全不依赖留出区域事件的旧天气系统；这一来源局限仍存在。不能把本次旧代理较低的 Brier 当成对旧代理科学合理性的全面背书。
2. **空间验证不是独立观测验证。** 52 个共享网格和空间相关性已披露。ERA5 没有明显技术质量反证，但本实验没有用独立站点量化观测误差。
3. **LAD-CV 是空间泛化，不是未来预测。** 同一天或同一风暴可以出现在训练/测试的不同区域；固定 OOF 的 LAD bootstrap 也未消除这些共同时间因素。不得将区间解释为全部时空依赖下的严格显著性。
4. **参数变动不等于物理机制变化。** 暴露尺度改变、罕见事件和外推均影响 θ/β；没有参数不确定性或机制识别分析。
5. **不能声称 ERA5 天气导致预测恶化。** 至少一个任务的实际算法没有取得可信的最优拟合，而且新旧暴露同时改变多项定义。本次证据支持是否达到采用门槛，不能识别来源变化的因果效果。

## 七、最终客观结论

**本次实验完成了天气替换和规定输出，但没有达到论文正文转正的验收要求。**

具体而言，111 个 LAD 的 ERA5 小时数据完整取得，121,656 行新面板及标签核对通过，没有发现本次采集/聚合存在覆盖或单位问题；新天气具有较好的空间连续性。然而，八个任务中只有两项出现极小的 Brier 改善，最大约 0.051%，不存在实质改善证据。校准结果有改善也有退化，原图的单样本尾箱和常数率现象不支持笼统的“明显更好”。

最稀有的天气归因 >1000 客户模型存在已证实的优化退化，因此其正式参数和有效模型比较仍处于**数值有效性未解决**状态。现有负向总体指标不能据此上升为“ERA5 本质上比旧代理更差”的结论；但即使单独查看其余七项，也没有转正依据。
