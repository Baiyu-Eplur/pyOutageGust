相对于历史程序，另有**统一数值修正**：稳定log-CDF似然、解析梯度和参数尺度、多初值及统一停止规则、精确同值分组，θ下限从2统一放宽到0.1并允许p0=0。所有候选同范围、同13初值规则、同预算。该变化单列为优化修复，不能称为仅由聚合引起的历史差异。

## 4. 是否跨折一致？其他任务有无代价？

主任务四个替代聚合均在5/5折比A01更差。重要次级A02/A03/A04在5/5折更差，A05在4/5折更差。四个替代对A01的主/次任务绝对改善条件95%区间均在0以下；这里是给定OOF预测的LAD条件区间，不包括重新拟合、候选选择和共享风暴/日期的不确定性，不是严格未来泛化或因果结论。

A01在8任务中的6项BS最低。A04/A05仅在两个 >1000稀有任务上有微小BS优势：全体 >1000分别改善4.67988×10⁻⁶、5.31881×10⁻⁶；天气 >1000分别改善5.98637×10⁻⁷、1.38658×10⁻⁶。对应条件区间均跨0，全体稀有任务4/5折改善，天气稀有任务3/5折改善，不能提升为全面优势。

A02、A03八项BS均比A01差。八任务平均相对改善（次级摘要）为A02 −1.0431%、A03 −0.2662%、A04 −0.0381%、A05 −0.0402%。这些结果不支持为替代指标另换主任务。

## 5. 是否优于训练折常数率？

40/40组有效候选任务的BSS为正，约0.00455–0.05228，即相对训练折常数预测的BS改善约0.455%–5.228%。因此当前LAD留出中，各种聚合都包含一定概率预测信息，但总体增益有限。

A01主任务BSS=0.0157687（1.5769%），次级=0.0463297（4.6330%）。这支持在限定验证范围内报告信息增益，不表示单一阵风指标已经充分解释区域风险差异。

## 6. 校准是否与Brier同向？

并不总是。主任务A04的校准RMSE由A01的0.00243111降至0.00232762（改善4.26%），但BS略差；重要次级A02的校准RMSE改善48.56%，BS却退化1.7285%。不能事后以校准胜负替换Brier主判读。

按冻结的共同箱规则，A01在主任务、次级、天气 >1000均有一个n=1的最高概率尾部箱。该单样本箱分别贡献这三项分箱平方校准误差的13.84%、42.12%、96.47%。天气 >1000中，A02的RMSE相对A01改善92.20%，但这很大程度受尾部箱支持和分箱结构影响；它并没有同时改善该任务的BS。不能把该大百分比视作稳定的整体校准优势。

原始分箱、n=1点和所有指标完整保留，没有删除或重新合箱。原自动图的“全非空箱放大”因尾部频率=1而与全范围图重复，故审查目录另附**同一保存箱、仅调整显示范围**的辅助视图：左图保留全部尾部点并标n=1，右图放大n≥100支持范围并注明落在放大范围外的点数。没有重拟合、改箱、改评分或覆盖原图。
