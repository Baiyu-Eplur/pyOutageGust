## 5. 五种聚合方式：只计算这一组

设某地区日24个小时阵风为 \(g_0,\ldots,g_{23}\)，升序为 \(g_{(1)}\le\cdots\le g_{(24)}\)。

| ID | 名称 | 精确定义 |
|---|---|---|
| A01 `daily_max` | 日最大阵风 | \(\max_h g_h\)；本轮主对照 |
| A02 `daily_mean` | 日均小时阵风 | \(\sum_h g_h/24\) |
| A03 `daily_q90` | 日内90百分位阵风 | 对24值使用固定linear插值分位数；即 \(0.3g_{(21)}+0.7g_{(22)}\) |
| A04 `top3_mean` | 最高3个小时值均值 | \((g_{(22)}+g_{(23)}+g_{(24)})/3\)，不要求连续 |
| A05 `max_rolling3h_mean` | 最大连续3小时均值 | \(\max_{h=0,\ldots,21}(g_h+g_{h+1}+g_{h+2})/3\) |

A05只用日内22个完整窗口，不跨日、不环绕、不用不完整窗口。三小时固定，不追加2/4/6/12小时竞赛。

A02不是持续平均风速，而是小时阵风值的均值，所有表图使用准确名称。

聚合不使用故障标签，可以提前算完整日表。保存五个指标、地区日键、折号、分布摘要与相关矩阵。A01必须在浮点容差内复现原 `grid_daily.csv` 的日最大值；若不一致先定位，不带着差异进入拟合。

用少量具有实际辨别力的检查验证聚合：常数序列、最高值连续/分散的序列、午夜两侧峰值、排序分位数；确认A05不跨日、A04不误作连续窗口。不为此建立庞大测试套件。

## 6. 统一脆弱性模型和数值修复

### 6.1 固定模型

对每个候选A和每个结果任务，拟合：

\[
p(A)=p_0+(1-p_0)\Phi\left(\frac{\log A-\log\theta}{\beta}\right),
\quad \theta>0,\;\beta>0,\;0\le p_0<1.
\]

二元Bernoulli最大似然、相同地区日等权。**函数形式相同，但每个训练折、每个聚合指标须重新估计参数。** 不直接套日最大值参数，不添加其他协变量，不更换link。

对A=0采用模型极限p=p₀，不能为避免log(0)删掉全天无风日或随意加常数。负阵风视为输入问题。

全样本拟合用于参数表和描述曲线，不能用于OOF预测、折内初始化选择、参数约束优化或校准。

### 6.2 先建立可靠的统一优化器

上一轮 `wthr_gt1000` 全样本和五折存在已证实的常数退化，合法参数点(40,0.27,0.0014)的NLL优于保存解。先在A01的这六个训练范围诊断并修复，然后冻结统一实现，用于全部候选。

优先检查：概率裁剪导致梯度消失、CDF数值饱和、参数尺度、边界和停止准则。使用稳定log-CDF，例如：

\[
\log p=\operatorname{logaddexp}\big(\log p_0,\log(1-p_0)+\log\Phi(z)\big),
\]

\[
\log(1-p)=\log(1-p_0)+\log\Phi(-z).
\]

参数可用logθ、logβ和logit(p₀)表示，正确处理允许的边界。先记录并检查原参数范围对五种指标是否构成不合理限制。需要统一改范围时，使用所有候选一致、与结果排名无关的规则并记录；禁止只给某个候选更宽边界或更高优化预算以改善其表现。

使用相同的有限多初值生成规则和优化预算，数值可根据各自训练指标尺度适配。预先固定初值数、种子与停止准则。A01异常诊断包含已知合法点；所有拟合保留常数率作为目标函数/预测退化参照。

采用训练数据对完全相同指标值作精确分组并使用计数计算Bernoulli似然可加速；不能为了加速先四舍五入指标，改变原目标函数。

保存所有初值解的参数、NLL、状态、迭代、边界、预测标准差和候选选择理由。必要时有限预算备用优化，触发规则对所有候选一致，不无限重启。

判定要求：选中解不应比已评估的合法候选更差；不存在已知更优点反例；多个起点的目标表现可核对。success=true不单独作为通过标准。近似相同NLL对应很不同参数时，标记弱识别，不能宣称稳定θ。

无法解决的拟合记录为无效并保存诊断；不要悄悄用常数率填补成“有效脆弱性模型”。仍可报告其算法输出作为失败诊断，但不得用它证明该聚合指标更差；其余任务继续完成。

### 6.3 公平比较的基线

全部五种候选都使用修复后统一优化器。**聚合效应的直接对照是本轮修复后的A01，不是原运行中含优化失败的A01。**

另列原A01与本轮A01的差异，以区分优化修复效果与聚合效果。保存失败原记录，不覆盖历史报告。

## 8. 评价与展示

### 8.1 主指标与基准

对每任务、每候选报告：

- 全部OOF行的Brier：\(BS=\sum_i(p_i-y_i)^2/N\)，不以不等样本量的逐折BS简单平均替代；
- 相对本轮A01的改善：\(G=(BS_{A01}-BS_A)/BS_{A01}\)，以及绝对差；
- 五折各自的BS、改善幅度和方向；
- 相对于训练折常数事件率预测的Brier skill：\(BSS=1-BS_A/BS_{const}\)。

常数基准仅用每个训练折的事件率预测其测试行，八任务各一套，与聚合方式无关。不得用全样本或测试事件率替代。不增加logit/cloglog候选，本轮严格固定同一脆弱性形式。

可低成本输出log loss作为辅助诊断，但不能事后用其胜负替代预定Brier主比较。数值裁剪如仅用于评价须统一、记录，并与稳定拟合似然区分。

主要判读任务：全体>100客户。重要次级任务：天气归因>100客户。其余六任务完整报告。八任务平均相对改善仅为次级摘要；含无效拟合时明确标为不可作有效总体比较，不随意删一组后把七任务均值当新的主验收。

不设事后5%或其他新转正门槛。解释绝对量级、相对量级、跨折方向和校准；允许结论为“差异很小，未显示值得替换日最大值的优势”。也不因没有显著差异而宣布严格等效。

### 8.2 不确定性：只复用一套轻量方法

如原配对LAD bootstrap代码可用，复用固定OOF、整LAD配对抽样1000次、固定同一随机种子，估计每候选相对A01的Brier差异区间；可用LAD层损失汇总高效计算，重采样时保留行数权重。

这是给定当前预测的LAD层条件区间，不包括重新训练、候选选择和共享风暴/日期的全部不确定性。不以区间作严格因果结论，也不开展新的bootstrap体系。

### 8.3 校准与样本支持

本轮预先固定一种统一展示规则：对每个任务，将五候选的有效OOF概率合并，以不使用标签的合并概率十分位点生成共同箱边界；边界补0/1，去重，同一概率不拆箱。保存精确边界和浮点读取设置。

- 所有候选对该任务使用同一组边界；空箱留空，不填0或插值。
- 每箱列样本数n、阳性数、平均预测和实际频率。
- n<100的箱显示为稀疏点、不连成校准趋势线；不删除、不据结果合箱。若全体概率近常数只有少数箱，按实际展示。
- 图采用统一坐标，并可另加主要概率区间放大图；完整范围和尾部支持始终可见。
- 分箱校准RMSE按既定样本量加权，列出绝对值及相对A01变化。共同分箱依赖当前预测集合，是描述性诊断，不用作反复优化的目标。

发生率—指标曲线与校准图分别制作：前者横轴为各自日度指标、后者横轴为预测概率。五种聚合的“20 m/s”含义不同，不将不同横轴下参数位移解读为真实物理阈值变化。
