## 2. X01-B：共同估计对象与九个候选

### 2.1 直接拟合原尺度条件均值

本轮目标是客户数/小时的条件算术均值，采用：

\[
\mu_i=E(Y_i\mid g_i,x_i,\text{记录事件})
=\exp(\alpha+x_i^T\gamma)\,r(g_i;\theta),\qquad r(g)>0.
\]

这是一个可检验的乘法均值工作模型，不保证正确、不识别因果。所有模型共同采用同一控制项；只改变阵风响应r。

给定训练数据的参考阵风g_ref，统一设置r(g_ref)=1以解决截距与曲线尺度的重复识别。g_ref可取训练阵风中位数；每折保存，并在预测/导数中正确还原物理m/s。参考点改变不应改变同一条拟合曲线。

为了公平比较，固定每个任务的均值估计准则：

- E：Poisson伪似然均值损失，逐条为`μ − y·log(μ)`；y=0项用正确极限处理。
- R和R_C：Gamma型均值损失，逐条为`log(μ)+y/μ`，要求y>0。

这些是本轮预设的工作损失；不把D当作计数，不声称观测分布或方差假设已经成立。报告中区分均值模型与完整概率模型；不据伪似然直接套普通AIC、似然比p值或Poisson/Gamma预测区间。群组重抽样用于主要不确定性描述。

实现可使用适合的GLM/GAM软件及非线性优化。用于比较的数学目标必须一致；若软件内部优化的是总损失而另一实现使用平均损失，要同步惩罚尺度。

原log-OLS若已容易复现，可以另作历史对照；不得将其log尺度R²与上述原尺度R²混排，也不得用naive exp转换冒充条件均值。主比较中的M02指在共同新估计准则下的二次模型。

### 2.2 必须尝试的候选

下表中u可以为按训练参数标准化的阵风，g必须保留可还原的物理单位。任意未约束曲线只需保证μ>0，不强制导数为正。

| model_id | 候选 | 定义/要求 |
| --- | --- | --- |
| M00 | 无阵风参照 | r(g)=1；评估gust是否提供额外信息 |
| M01 | 线性预测子 | r(g)=exp[β(u−u_ref)]；β自由，可增可减 |
| M02 | 二次预测子 | r(g)=exp[β1(u−u_ref)+β2(u²−u_ref²)]；β1、β2均自由 |
| M03 | 无形状约束平滑样条 | r(g)=exp[s(g)−s(g_ref)]；控制平滑程度，允许局部下降 |
| M04 | 单调非递减样条 | r(g)=exp[s(g)−s(g_ref)]，s′(g)≥0；允许近似平缓，不强制S形 |
| M05 | Softplus | v(g)=1+b·h·log(1+exp((g−τ)/h))；r=v(g)/v(g_ref)，b≥0、h>0 |
| M06 | 带基线的对数正态CDF | v(g)=1+A·Φ[ln(g/g50)/s]；r=v(g)/v(g_ref)，A≥0、g50>0、s>0；g=0用CDF右侧极限0 |
| M07 | 带基线的Logistic | v(g)=1+A/[1+exp(−(g−τ)/h)]；r=v(g)/v(g_ref)，A≥0、h>0 |
| M08 | 带基线的Gompertz | v(g)=1+A·exp{−exp[−(g−τ)/h]}；r=v(g)/v(g_ref)，A≥0、h>0 |

以上用固定基线1和整体截距表示原先的“a+A·F(g)”家族，避免a、A和截距同时自由造成比例不可识别。需在文档中给出此等价关系及正基线假设；不要把1解读为固定一位客户或一小时。

M01/M02在原尺度上是指数化线性/二次预测子；M06–M08是直接作用于原尺度均值的缩放CDF/S形，不得实现为exp[A·CDF]后仍声称同一个模型。

M07/M08的下渐近平台在g→−∞，物理风速g≥0内未必观测得到；报告实际物理支持内的基线和变化，不把不可达的负风速区间当数据支持。

Lognormal的g50、Logistic的τ分别对应其基础CDF达到0.5的位置；Gompertz的τ对应1/e，不可统称“50%点”。Softplus的τ为基础曲线半斜率位置。它们均不自动是损伤阈值；最终统一的原尺度派生量应另行计算。

所有任务都必须尝试M00–M08，即27个任务—模型组合；“尝试”包括可复核的失败。不能跳过失败模型后称已测试全部，也不能把不收敛当成已证明该曲线不适合。

这是基于已有OOF预测的条件重抽样，未包含重新训练、调参和选型全部不确定性。报告中必须说明，不能将其作为经过多模型选择校正的确认性显著性结论。若群组少或存在未解决依赖，明确限制。

### 5.2 入围曲线的稳定性

每个主要任务至少对两个有竞争力且数值有效的候选进行群组Bootstrap重拟合，默认200次；R_C同样在有意义时执行。优先包括最好的约束模型与有效的自由样条，避免只对喜欢的S形给区间。

若无阵风参照已经最优或曲线幅度近零，不必为不可识别位置作昂贵的伪精确计算；重点报告效应/预测稳定性。

每次重抽样重新执行训练内预处理，并将派生量转回同一物理单位和同一参考场景。默认固定在全训练数据已选的平滑超参数，明确区间以该选择为条件；不声称已覆盖模型选择不确定性。重复群组通过权重或唯一副本ID正确处理，不能被事件去重逻辑删除。

保存失败/越界的重抽样结果与原因，不只保留漂亮的有效子集。稀疏高风速导致Bootstrap中缺失关键支持时，如实报告。

先短跑计时，设置检查点和可续跑机制。完成每个外折及每25次重抽样保存进度。计算预算不足时优先保证全部候选的主要OOF比较，剩余重拟合标为未完成并给续跑命令；不擅自以少量重抽样声称200次已完成。

### 5.3 推荐规则

按以下顺序形成暂定建议，不替作者最终定稿：

1. 先检查数值有效、人口可比、OOF覆盖及泄漏；不合格不进入完整排名。
2. 按预设主指标排序，同时呈现原尺度误差、校准、尾部风险和相对M00的提升。
3. 差异小且不稳定时，优先考虑较简单、较稳定、假设较弱的模型，但报告“当前无法明确区分”；不得用不显著差异证明等效。
4. 区分“预测可用”和“平台/位置可解释”。一个S形模型可以预测尚可但平台参数不可识别；此时不能据此宣布物理饱和。
5. 约束模型没有下降段是设计事实；其证据来自与自由曲线及参照的预测/稳定性比较。
6. 每个任务独立推荐；不同任务或场景存在权衡时，输出短名单及选择理由，不凑成全论文统一曲线。

## 方法依据及实现参考

- [Baker（2015）：脆弱性函数与对数正态拟合](https://www.jackwbaker.com/Publications/Baker_%282015%29_fragility_fitting_EQS_final.pdf)。仅用于形状动机，不把事件后果均值误称资产失效概率。
- [Pya & Wood（2015）：Shape constrained additive models](https://link.springer.com/article/10.1007/s11222-013-9448-7)。形状约束平滑函数的统计框架。
- [CRAN scam文档](https://cran.r-project.org/web/packages/scam/refman/scam.html)。若使用该包，核对本地版本；例如mpi作用于平滑项，不能忽略整体模型的其他gust依赖。
- [Santos Silva & Tenreyro（2006）：The Log of Gravity](https://personal.lse.ac.uk/tenreyro/jensen08k.pdf)。支持区分对数结果OLS与原尺度均值伪似然；不是本项目均值规格正确性的保证。

只在确有实现问题时查官方文档或原始方法论文；不需要先开展新的全面文献综述才运行实验。
