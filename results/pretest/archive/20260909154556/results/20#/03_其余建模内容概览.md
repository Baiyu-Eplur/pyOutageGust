# Step 3：旧论文其余核心建模内容概览

以下均为v6论文实际采用的最终生产脚本（`01_建模画图脚本清单.md`分类A），逐一概述分析目的、模型、核心发现。核心发现数字均交叉核对自`项目研究框架与数据结果说明.md`第10节及v6正文，与代码逻辑一致。

## `0519_4.1.py`——基线非线性模型（Table 1 + Figure 4）

**目的**：检验阵风与两类停电结果（暴露、恢复）之间是否存在非线性关系。

**模型**：对`log(customers)`和`log(Duration)`分别估计log-OLS：
```
log(Y) ~ z_gust + z_gust² + z_precipitation_24h + z_temperature + z_pressure
         + z_gust:z_pressure + urban_binary + log_population
         + income_deprivation_rate + deprivation_gap_pct + morans_i
         + C(year) + C(month)
```
标准误按LAD聚类，样本n=44,821（完备案例）。

**核心发现**：
- 暴露侧：阵风一次项-0.0236**（负）、二次项+0.1107***（正）——凸性响应，拟合转折点约10.61 m/s。
- 恢复侧：阵风一次项+0.0342***、二次项+0.0479***（均正）——单调递增+加速，拟合转折点约8.11 m/s（比暴露侧更早进入加速区间）。
- 两模型R²均只有0.0375-0.0479，量级很小，论文自己明确承认"天气和现有区域变量只解释事件差异的一小部分"。

## `0519_4.2.py`——环境协同调节模型（Figure 5）

**目的**：检验阵风-停电关系是否受周边天气条件（温度、气压、降水）调节。

**模型**：在基线公式基础上，分别加入阵风×温度、阵风×气压、阵风×降水三组独立的交互项模型（不是三者同时进入一个模型），在低/中/高（z=-1/0/+1）三档情景下生成条件预测曲线。

**核心发现**：低温与更长恢复时间相关；低气压对应更高的拟合客户暴露；高降水下高阵风对应更高拟合暴露。恢复侧的阵风×温度、阵风×气压、阵风×降水交互项在双向LAD×日期聚类下依然显著，但暴露侧的部分交互项（尤其阵风×气压）在更保守的聚类方式下不再显著——论文据此建议"暴露侧环境调节应比恢复侧更谨慎解读"。

## `0519_4.3.py`——LAD条件区域比较地图（Figure 6）

详见 `02_LAD风敏感性地图方法精确复原.md`，此处不重复。核心发现：113个LAD在统一参考天气下条件预测差异显著；暴露与恢复两张预测面呈现强负相关（Pearson r=-0.893，Spearman rho=-0.879），说明拟合暴露高的地区不一定拟合恢复慢，两个维度捕捉的是不同的区域因素。

## `0519_4.4.py`——稳健性与规格稳定性（Figure 7/8）

**目的**：检验基线非线性发现是否对分布假设、极端值处理、聚类方式、恢复期天气窗口敏感。

**模型对照组**：
- 暴露侧：基线log-OLS vs Negative Binomial vs Tweedie vs p95截尾log-OLS。
- 恢复侧：基线log-OLS vs Gamma GLM vs Tweedie vs p95截尾log-OLS。
- 另外做高阵风限制样本（只用转折点以上的观测重新估计）。

**核心发现**：预测曲线的整体非线性形状在全部规格下定性保持稳定；关键系数（尤其阵风二次项）方向一致，但个别一次项/交互项在不同规格下精度有差异。

## `530_Work A.py`——聚类推断稳健性

**目的**：比较LAD聚类、日期聚类、LAD×日期双向聚类三种标准误方式，检验统计推断是否对聚类假设敏感。

**核心发现**：双向LAD×日期聚类后，暴露侧阵风二次项和气压主效应仍显著，但阵风一次项（p≈0.173）和阵风×气压交互（p≈0.221）不再显著；恢复侧的阵风一次/二次项、降水、温度、阵风×气压交互项在双向聚类下均仍显著。论文据此得出"最稳健的主张是阵风非线性结构本身，暴露侧的一次项和交互项不如恢复侧稳健"这一关键限定性结论。

## `530_Work B.py`——恢复期天气窗口稳健性（Appendix F.3）

**目的**：检验恢复模型的天气匹配方式（仅用事故发生时刻的天气）是否影响结论，因为恢复过程可能持续数小时到数天，期间天气条件会变化。

**方法**：利用本地缓存的逐小时天气数据（`data/weather_request_cache`），额外构造事故发生后固定6/12/24小时窗口内的天气汇总量（不使用实际恢复时长本身来定义天气窗口，避免用结果变量反向定义自变量导致的内生性问题），重新估计恢复模型。

**核心发现**：用固定事故后窗口替换事故时刻天气后，恢复侧非线性阵风关联基本保持一致，说明恢复侧发现不完全是"只用事故时刻天气匹配"这一简化假设的产物。

## `530_Section4_3_extra.py`——暴露-恢复预测面相关性检验（Appendix E2）

**目的**：定量检验Figure 6两张预测面（暴露/恢复）呈现的"视觉上此消彼长"模式是否具有统计显著性。

**方法**：直接读取`0519_4.3.py`产出的`pred_customers_vulnerability`/`pred_duration_vulnerability`两列（113个LAD配对预测值），计算Pearson和Spearman相关系数，并做分位数交叉表（Q1-Q4象限分析），识别"高暴露低恢复时长"的典型LAD。

**核心发现**：Pearson r=-0.893、Spearman rho=-0.879，均p<0.001，强负相关。脚本自身的解读文字明确声明"这是基于同一固定天气情景下模型预测的描述性LAD层面检验，不是估计新的因果模型"。
