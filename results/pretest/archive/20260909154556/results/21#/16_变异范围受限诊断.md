# Step 1：变异范围受限诊断

## 方法：Thorndike直接变异范围受限公式（推导过程）

设(X,Y)服从双变量正态、线性关系Y|X不变（回归斜率β和残差方差不随取值范围变化，只有观测到的X的方差范围变化），若X的标准差因筛选被压缩为原来的比例`u = SD_受限/SD_未受限`，可以推导出受限后的相关系数：

```
Var(X_受限) = u² · Var(X_未受限)
残差方差 σ_ε² = σ_Y²(1-ρ_full²)   [不随受限变化，因为回归关系本身不变]
β²σ_X² = ρ_full²σ_Y²              [回归斜率与相关系数的关系]
Var(Y_受限) = β²·Var(X_受限) + σ_ε² = σ_Y²[ρ_full²u² + 1 - ρ_full²]
Cov(X_受限,Y_受限) = β·Var(X_受限) = ρ_full·u²·σ_X·σ_Y

ρ_受限 = Cov / (SD(X_受限)·SD(Y_受限))
       = (u · ρ_full) / √(1 - ρ_full² + u²·ρ_full²)
```

这就是经典的Thorndike Case 2直接变异范围受限公式。**当u<1（真正受限/压缩）时，公式预测ρ_受限<ρ_full（相关系数机械性衰减）；当u>1（范围反而扩大）时，公式预测ρ_受限>ρ_full（相关系数机械性增强）**——本命令按此公式的两个方向都做计算，不预设方向。

## 判断：变异范围受限只能解释观测模式的一部分，且解释力因风暴而异，不能一概而论

**E0（暴露）**：变异范围受限对Arwen、Dudley、Ciarán、Henk四场（方向一致）有一定解释力，尤其Arwen、Henk的理论值与观测值数量级接近；但对Eunice、Babet两场，理论预测方向与实际观测方向相反——这两场风暴纯粹用"变异范围"这一个统计现象**不能解释**观测到的相关系数变化，必然存在其他因素（很可能正是命令#24原文讨论的"运营异质性"，或者Eunice这类极端风暴期间Cause Code构成、区域集中度等结构性差异）。

**R0c（恢复）**：情况更复杂——理论上多数风暴的预测值η标准差比值接近1（0.85-1.45之间），意味着变异范围受限对R0c的预测相关系数衰减这件事上**整体贡献有限、不是主导因素**；命令#24发现的"全部7场风暴恢复侧相关系数系统性低于基准"这一现象，按本诊断的理论计算，**只有Arwen、Dudley、Babet三场的方向与"受限导致下降"一致，Eunice、Franklin、Ciarán、Henk四场理论上应该持平或更高，但实际观测全部走低**——这更清晰地指向：**R0c在风暴期间预测精度系统性走弱，主要不是变异范围受限这个纯统计假象造成的，而是命令#24原文已经讨论的运营异质性等实质性因素在起作用**，本次量化诊断为这一判断提供了额外的定量支持。

**总结（不给单一夸大的百分比数字，如实呈现复杂全貌）**：变异范围受限是一个真实存在、但作用方向和大小因具体风暴而异的统计现象，不能简单归纳成"能解释X%的降幅"这一个数字（因为部分风暴的理论方向与观测方向相反，用百分比框架反而会产生误导性的、甚至是负数或超出100%的荒谬结果，已在原始数据文件中如实保留但不作为叙事主线使用）。**对于本项目最关注的R0c恢复侧系统性走弱这一现象，本诊断的证据倾向于支持"运营异质性等实质性因素起主导作用"这一解读，而不是"纯粹是变异范围收窄的统计假象"。**
