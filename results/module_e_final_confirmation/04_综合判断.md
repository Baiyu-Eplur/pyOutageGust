# Step 4：综合判断——holdout是否确认了开发样本的发现

这是本项目论文一实证部分的最终headline结果，逐项如实回答，不回避负面信号，也不过度解读单次小样本holdout的波动。

## 问题1：E0暴露模型的阵风效应（方向、量级、临界风速）在holdout上是否得到确认？

**部分确认——凸性本身得到确认且增强，但线性项方向与具体临界风速数值未被确认，这是一个需要在论文中如实披露的分歧。**

| | 干净开发样本 | Holdout |
|---|---|---|
| 一次项 | -0.0842（负） | **+0.0661（正，p=0.0066）** |
| 二次项 | +0.0898（正） | **+0.1661（正，约1.85倍）** |
| 拐点z-score | +0.4769（高于均值） | **-0.1988（低于均值）** |
| 临界风速 | 12.13 m/s（第75.3百分位） | 换算后落在均值以下 |
| Bootstrap CI(z) | [0.232, 0.836]（不跨零） | [-0.548, 0.087]（**跨零**） |

- **得到确认的部分**：阵风对customers_v2存在真实的非线性（凸性）关系这一定性判断——二次项在两个样本里都是正、都高度显著，holdout的二次项量级甚至更大（约为开发样本的1.85倍）。"阵风与暴露规模之间不是简单线性关系"这一核心论点是稳健的。
- **未得到确认的部分**：①一次项方向发生反转（开发样本为负、holdout为正）；②拐点位置从"高于均值、对应偏高阵风区间"移动到"低于均值、对应偏低阵风区间"——holdout样本里，在几乎整个观测阵风范围内，customers_v2随阵风增大基本持续上升，没有复现开发样本"先降后升、临界点在第75百分位附近"的完整U型轮廓；③Bootstrap置信区间从不跨零变为跨零，具体的"临界风速=12.13 m/s"这一量化断言的证据强度在holdout上被削弱。

## 问题2：R0c恢复模型的阵风二次项（核心稳健发现）在holdout上是否得到确认？

**明确确认。** 阵风二次项在holdout上系数+0.0638、p=1.3×10⁻⁸，与开发样本已确立的稳健区间（+0.0682~+0.0918，视具体版本）方向一致、量级吻合。阵风一次项在两个样本里都不显著，结论一致（"一次项证据弱、不作为正式声明"）。**这是本次confirmatory检验里最清晰的正面结果**——本项目从命令#1起就在寻找的"阵风对恢复时长存在稳健的非线性效应"这一核心论点，经过完整独立的样本外时间窗口检验后依然成立。

## 问题3：customers_v2的效应（含n_stages构成效应模式）在holdout上是否得到确认？

**明确确认，包括方法论层面的n_stages构成效应解释。**

- customers_v2原始（未控制n_stages）设定下的系数方向在holdout上完全一致（一次项正+0.4592、二次项负-0.4509，均与开发样本同号，量级相近或更大）。
- **更重要的是**：对holdout样本单独重复命令#18的n_stages分层检查，单阶段子集（占holdout样本60.7%，n=7,279）内部customers_v2-duration_B关系呈现（近似）单调下降（9.26→9.21→3.66），**与开发样本命令#18发现的模式完全一致**——holdout独立证实了"customers_v2/duration_B表观非线性关系主要是n_stages构成效应，而非customers规模独立的因果非线性效应"这一方法论判断。**这不只是简单复现了一个系数，而是复现了整个诊断链条的结论，是本次confirmatory检验里第二个清晰的正面结果**。

## 问题4：E0一次项/临界风速未被确认的可能原因讨论

按命令要求，讨论可能原因，不回避也不过度解读：

1. **样本量差异**：holdout（n=12,114）约为开发样本（n=48,323）的25%，按本项目命令#5/#10/#16已反复验证的"样本量对系数稳定性有主导性影响"这一教训，仅凭样本量缩小到四分之一，线性项（本项目历次分析中一贯是四个系数里精度最低、最容易受样本量影响的一项）的估计噪声显著增大是完全可以预期的，不需要额外解释。
2. **季节覆盖单一**：holdout只覆盖单一连续的秋冬季（2023年9月末-2024年3月末），而开发样本跨越近2.5年的全季节数据。命令#16已发现locked窗口的阵风典型水平（均值10.82 m/s）高于开发样本（约9.6-9.7 m/s），这种季节性阵风分布差异可能真实地改变了"低阵风区间"和"高阵风区间"在这个特定半年窗口内各自包含的事件构成，进而影响拐点估计对应的具体位置——这是一个**无法用本次数据完全证实或证伪、但物理上合理**的解释路径。
3. **真实存在的时间不稳定性**：也不能排除阵风一次项本身的效应在不同时间段确实不稳定（本项目从命令#1起就发现一次项系数是四个系数里最脆弱的一个，在多个此前的稳健性检验里都表现出比二次项更强的样本依赖性）——如果如此，这反而印证了本项目一贯的判断："二次项（凸性）是核心稳健发现，一次项的精确方向和量级不应作为强结论报告"，这与开发样本阶段的既有认识是一致的，不是一个全新的问题。
4. **本命令不对三种解释做取舍**：三者都是合理的候选解释，本次holdout检验的样本设计和方法无法把它们分离，如实并列报告，不强行选择一个作为"最终解释"。

## 最终结论摘要（可直接用于论文实证部分）

> 本文的核心因果发现——**阵风对停电恢复时长存在稳健的正向二次项（凸性）效应**——通过了严格的样本外时间窗口确认性检验（locked_temporal_test，2023年9月末至2024年3月末，与全部探索性分析和模型规格选择过程完全隔离）：该效应在holdout样本上方向一致、统计显著（p=1.3×10⁻⁸）、量级与开发样本高度吻合。**customers_v2/duration_B表观非线性关系是阶段数（n_stages）构成效应而非customers规模独立因果效应**这一方法论判断，同样在holdout上得到独立复现。
>
> **暴露模型中阵风对customers_v2的非线性（凸性）关系本身得到确认且在holdout上表现更强，但具体的临界风速数值（开发样本估计为12.13 m/s）未能在holdout上得到确认**——holdout样本显示的阵风-暴露关系在观测范围内更接近持续上升而非"先降后升"，一次项方向出现反转，临界风速置信区间转为跨零。本文据此采用更审慎的表述：报告阵风对暴露规模存在稳健的非线性效应，但不再将12.13 m/s这一具体临界风速数值作为跨时间稳定的确定性结论呈现，而是标注为"基于开发样本估计、未通过独立时间窗口确认的探索性数值"，并将这一分歧及其可能原因（样本量、季节覆盖、潜在真实时间异质性）作为论文限制章节的一部分明确讨论。
