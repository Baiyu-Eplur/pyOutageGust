## 回答问题1：naive在121,313样本量下二次项CV是否也大幅下降？

**是，而且降幅几乎和duration_A/duration_B一样大。** legacy R0二次项CV=3370%（近乎无意义的巨大波动），naive在大样本下二次项CV降至**22.77%**——降幅达到99.3%，已经进入与duration_A（27.04%）、duration_B（16.40%）同一数量级的稳健区间，且naive的22.77%正好落在duration_A和duration_B两者之间。一次项也是同样的模式：legacy 44.46%（且5折中只有1折显著）→ naive大样本13.26%（5/5折显著）。

**结论：naive-大样本本身就已经接近duration_A/duration_B的稳健程度，没有出现"naive在大样本下依然像legacy一样不稳定"的情况。**

## 回答问题2：量化拆解——样本量效应 vs 变量重定义效应

以二次项CV为例，按命令建议的拆解方式：

```
legacy (3370%) → naive大样本 (22.77%)：样本量效应（含Cause Code范围从两组扩大到六组），降幅 3347.2个百分点，占总降幅的 99.85%
naive大样本 (22.77%) → duration_A (27.04%)：变量重定义额外贡献 = +4.27个百分点（变差，非改善）
naive大样本 (22.77%) → duration_B (16.40%)：变量重定义额外贡献 = -6.37个百分点（改善）
```

一次项CV同样拆解：

```
legacy (44.46%) → naive大样本 (13.26%)：样本量效应，降幅 31.2个百分点，占总降幅（相对duration_A的34.31个百分点总降幅）的 90.9%
naive大样本 (13.26%) → duration_A (10.15%)：变量重定义额外贡献 = -3.11个百分点（改善）
naive大样本 (13.26%) → duration_B (23.93%)：变量重定义额外贡献 = +10.67个百分点（变差）
```

**明确结论**：
1. **legacy→naive-大样本这一步（纯样本量效应，含Cause Code范围扩大，定义完全未变）贡献了绝大部分（一次项约91%、二次项约99.85%）的CV下降**，与命令#5此前"n=9,122→36,124本身就能让R0从不稳健变稳健"的教训完全一致，本次进一步证实并量化了这一效应在更大样本（116,125，约12.7倍于legacy）下依然主导。
2. **customers_v2/duration_A或duration_B相对naive-大样本的额外边际贡献很小，且方向不一致**：duration_A让一次项更稳（-3.11pp）但二次项变差（+4.27pp）；duration_B相反，让二次项更稳（-6.37pp）但一次项变差（+10.67pp）。**没有证据表明customers_v2/duration的重新定义在"折间数值稳定性"这个维度上带来了系统性的额外改善**——两个新定义各自在某一项上略优、另一项上略劣于naive，边际贡献量级（个位数到十位数个百分点）远小于样本量效应（上千个百分点）。

## 对命令#7-9重建工作价值的说明（如命令提醒，不做委婉淡化）

这一发现**不代表命令#7-9的独立重建工作没有价值**。命令#8已经证实customers_naive（仅取最早阶段）系统性低估了多阶段事件的真实客户影响规模（均值只有customers_v2的约54%），duration_naive同样只反映最早单一阶段的时长、完全忽略了后续阶段——**customers_v2/duration_A/duration_B在"数值本身是否准确反映真实事件规模"这个更根本的问题上仍然是明确的改进**，只是这次的验证目标（折间系数稳定性）恰好主要是被样本量支配的，重新定义在这一个特定指标上的边际贡献有限，这是两件不同的事，如实报告即可。
