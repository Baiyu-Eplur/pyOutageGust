# X02：风暴期间事件后果的专用建模与跨风暴验证

日期：2026-09-07。版本：1.0。性质：基于已观察Figure 9提出的回顾性新探索。

## 1. 研究问题与Figure 9的正确解读

本次检验：只用风暴期间的数据训练，能否比全时期训练更好地预测另一场风暴中的事件后果？收益来自重新估计平均水平、改变阵风曲线，还是增加了与事件差异相关的信息？

Figure 9横轴是观测后果，纵轴是模型预测后果，均在对数尺度；它不是阵风—后果曲线。因此，图上的水平带不能直接说明应把阵风函数拟合成水平线、S形或其他形状。

预测变化比观测变化小，可称为“预测范围压缩”：低观测值常被高估，高观测值常被低估。若预测几乎为常数c，则残差z−预测≈z−c，误差并不恒定；在预测—观测图上，统一加减一个截距只能平移水平带，不能让它沿45度线分布。

这种现象可能来自：一般时期与风暴时期关系不同；现有变量不能区分同一风暴内的事件后果；未建模的变量交互；变量或时间匹配误差；训练截尾与评价人口不同。图形不能独自区分这些解释，也没有证明剩余变异全是不可约噪声。

在平方损失下，理想预测m(X)=E[z|X]满足Var(z)=Var(m(X))+E[Var(z|X)]。条件均值本来就可能比单个观测集中。进一步缩小人口可能使条件关系更一致，也可能缩小阵风变化范围、减少样本与独立过程数，因此不保证提高R²。

## 2. 两个研究轴与明确假设

| 研究轴 | 假设 | 判定证据 |
| --- | --- | --- |
| 训练人口 | 风暴期间重新估计有利于跨风暴预测。 | 同一模型/变量/评价事件下，风暴训练与全时期训练直接比较。 |
| 平均水平及曲率差异 | 全时期模型只需一个共同风暴偏移或阵风交互即可改善。 | 全时期二次模型与加入风暴指示及其阵风交互的模型比较。 |
| 曲线形式 | 专用人口中阵风函数需要不同形状。 | 同一风暴训练人口和控制下比较一次、二次、Softplus、自由样条。 |
| 多变量信息 | 单一阵风函数不足，交互信息有助于区分事件。 | 同一信息集下，小规模树模型与二次模型比较。 |
| 工程新信息 | 时间可用的天气历时/运行状态能提供增量信息。 | 仅在来源和时间戳可核实后，用固定模型比较核心与扩展特征。 |

不得根据测试结果定义风暴、筛选“大噪声”事件、只留容易拟合的风暴或改评价指标。

## 3. 数据目标：先衔接Figure 9，再评价新方案

### 3.1 审计性复现

本地Codex先定位当前修正项目中实际生成Figure 9的代码、数据、公式、预测档案与稿件版本。当前对话可读旧MD7的4.3称使用全样本最终模型生成风暴拟合值；因此需检查逐事件训练重合，不能预设Figure 9是样本外预测图。复现与新模型结果分别保存。

记录事件唯一ID、C和D定义、D单位、零客户处理、p99截尾来源、风暴窗口归属、对数底数、所有控制项，及图中空心三角形对应哪些排除事件。缺少精确复现所需产物时注明缺口；不得利用图片反推一组数值充当原数据。

### 3.2 新实验的主要任务

- **E_log：** z=ln(1+C)，保留数据合同允许的零客户事件。
- **R_log：** z=ln(D/1小时)，D>0；只使用核心信息集。
- **R_C_log：** 与R_log相同，但增加最终ln(1+C)及其平方，用于与原恢复规格衔接；明确这是事后条件分析，不与R_log共同争夺“实时预测冠军”。

E和R分别建立资格条件，不因E任务不需要的D缺失而删除E样本。主评价不按测试结果p99删除极端恢复事件。原稿的截尾人口保留在复现支线；若检验训练截尾效果，阈值只能在每次训练集估计，所有模型仍预测并评价共同的完整测试人口，另报超过训练阈值的结果描述。

主评价对数平方误差，与图示目标相连。原尺度图与MAE可辅助展示，但exp(预测对数)或exp(预测对数)−1是回变换后的中心预测，通常不是原尺度条件算术均值。不能把对数OLS的误差与X01原尺度均值模型的误差直接归因于“换了人口”。如另做原尺度均值估计，须单立目标和模型比较，本轮不默认扩展。

### 3.3 分析人群与风暴归属

以本地经修正的数据合同为父人口；明确其是否仅包括weather_natural与technical_asset。主风暴子集由预定日期窗口与事件开始时间定义，不根据Cause Code、阵风分位数或结果挑选。若父人口已有原因限制，仍只能称该限定人口的风暴事件分析。

可报告weather-only子集作为事后敏感性，但它不等同于风暴窗口人口，也不自动构成事件发生时可使用的分类信息。七场风暴是当前论文选用的集合，不宣称是期间所有命名风暴的完整枚举。

## 5. 两条验证路径，按顺序执行

### 路径A：前五场开发、最后两场时间测试（主要）

1. 开发风暴：Arwen、Dudley、Eunice、Franklin、Babet；实际是P1、P2、P3三个保护组。
2. 测试风暴：Ciarán与Henk；在新实验开始时固定。最后两个名称按时间选择，不能依据成绩更换。
3. 开发内部采用三折留一过程组验证，每折两个组训练、一个组验证。全部预处理、调参和人口比较都只接触该折训练标签。
4. 根据开发验证预定指标选定配置，使用全部开发数据重拟合，然后一次性输出两场测试结果。模型拟合截止为首个测试窗口开始前48小时；按上述代理配置为2023-10-29 00:00 UTC。全时期基线也不得使用该截止后的普通事件。
5. 两场测试均使用同一冻结模型，期间不更新Henk模型。训练所用结果必须在拟合截止前已可确认；未完成事件不能用事后最终D/C当作截止时已知标签。若标签发布时点缺失，按可验证的结束时点作下界并记录其限制，不能宣称在线部署复现。
6. 验证折剔除与验证窗口及其前后48小时保护区相交的训练事件/信息窗口，及共享同一事件或过程的记录。跨期长恢复事件不能凭开始时间在训练集就绕开保护；保存逐项排除理由。

三个过程组无法提供五个独立的风暴验证折。这里三折比强行将同一过程随机拆为五折更贴合“预测另一场风暴”的问题。留组方法本身见[scikit-learn分组交叉验证说明](https://scikit-learn.org/stable/modules/cross_validation.html)。

### 路径B：全部五个保护组的五折跨过程验证（次要）

路径A完成并封存模型选择、配置和两场结果之后，再做P1–P5留一过程组的五折评价。每次保留完整过程组，余四组用于训练；有调参需求时仅在这四组内留组调参。各预定家族分别报告，若报告自动选型管线，则家族选择也必须发生于外层训练内。

这条路径检验跨已观察过程的可迁移性，不是向未来的滚动预测，有些折可用后期过程训练预测早期过程。它也不是对路径A完全独立的重复确认，因为使用同一批历史风暴。其结果不得反过来改路径A的模型或测试组合。

分开内层选型与外层评价可减少调参后直接汇报同一验证分数的乐观偏差。[scikit-learn嵌套验证说明](https://scikit-learn.org/stable/auto_examples/model_selection/plot_nested_cross_validation_iris.html)

所有七场风暴已经参与此前图表与研究判断，因此本轮最多称“重新冻结协议下的回顾性跨风暴评价”，不能重新命名为从未接触的独立确认集。

## 6. 最小且可归因的模型集合

所有同任务模型必须在完全相同的评价事件、目标尺度和特征信息级别上比较。每个折全时期模型剔除当前验证/测试过程及保护区；主时间路径还遵守统一日期上限。

| ID | 模型 | 训练人口 | 用途 |
| --- | --- | --- | --- |
| B00 | 训练风暴的对数结果均值 | 风暴 | 检查是否只需风暴平均水平；不能用测试风暴均值。 |
| B01 | 核心控制，无阵风及其派生/交互 | 风暴 | 阵风增量基线。 |
| G02 | 二次阵风工作模型 | 可用全时期 | 与原思想对应的公平重拟合参照，不能直接用已见测试数据的旧系数。 |
| P00 | G02加共同风暴指示I_storm | 可用全时期 | 检查风暴平均水平调整。 |
| P02 | P00加I_storm×g及I_storm×g² | 可用全时期 | 部分共享控制、允许风暴阵风曲率不同。不是各风暴名称固定效应。 |
| S01 | 一次阵风 | 风暴 | 判断风暴子样本是否需要二次曲率。 |
| S02 | 二次阵风 | 风暴 | 与G02直接识别训练人口效应。 |
| S03 | 自由三次样条阵风 | 风暴 | 不预设转折或单调的形状参照。 |
| S04 | 单调Softplus阵风 | 风暴 | 平缓后上升的工程形状参照。 |
| G05/S05 | 相同的小规模梯度提升树方案 | 全时期/风暴 | 检查同一核心信息集内非线性交互，成对比较以免混淆人口与模型。 |

核心曲线模型统一采用z=α+x′γ+f(g)，控制集一致；本轮主比较压力作为主效应，默认不含gust×pressure，便于归因阵风曲线差异。旧稿如含该交互，仅在桥接支线为G02/S02同时加入，并分别命名；主曲线与原稿完整规格的差异必须披露。不得把无交互模型冒称原图的精确复现。

S04定义为f(g)=b[h·log(1+exp((g−τ)/h))−h·log(1+exp((g_ref−τ)/h))]，b≥0、h>0，阵风以m/s计。此处Softplus直接作用于对数结果均值，不是X01的原尺度乘法均值方案。τ、h由训练数据优化；函数单调是约束，不是数据证明。固定参考g_ref只影响截距，不赋予τ物理损伤阈值含义。

复杂度冻结为小网格，见Codex指令。不启动神经网络、大规模AutoML、逐风暴独立曲线或更多CDF家族。保留所有失败候选和收敛状态。

## 7. 信息集与工程预测边界

**F0核心（本轮主线）：** 经审计的阵风、气压、温度、降水、地点/区域属性及可迁移日历项。将天气产品与时间窗口说明清楚；若使用事后实测日最大阵风或整日降水，这只能称在已知天气条件下的回顾性事件后果预测，不是风暴到来前的预测。

用于未来年份/月份的特征必须有定义。新实验统一用年内周期项和预定义时间趋势等可迁移编码；不将未见年份固定效应默认为零后声称与旧模型规格一致。区域类别的未知处理、标准化和填补均由训练折拟合。

最终Cause Code、最终客户规模、恢复阶段数、恢复结束时间及同场风暴最终总量不进入F0。R_C_log有意加入最终客户规模，明确单列为事后条件支线。

**F1扩展（条件执行）：** 若项目已有带时间戳记录，可增加截至事件开始前的6/24小时阵风或降水统计、固定区域内既往24小时新事件数、开始前仍未恢复的事件数。构造只能使用当时可获得的记录；同一时刻排除当前事件，排序一致。未决事件数可以用开始/结束时间判定t之前状态，不能使用它们未来最终持续时长、客户总量或最终原因作为属性。只有离线重建记录而缺少发布延迟时，应标注“理想化历史状态”，不能称真实可用实时特征。

新增特征若可用，在读取测试标签前冻结清单，仅对固定的S02和S05补做F0/F1对照。不可用则如实跳过，不虚构网络资产、拓扑、抢修资源或预报档案。不得将测试阶段观测到的最终负荷总量当作输入。

## 8. 指标、残差诊断与选型

### 8.1 主指标

对每个验证过程j计算MSE_j=mean((z−z_hat)²)。开发选型采用各过程等权的macro-MSE，避免Eunice事件多而独占目标。并报告事件等权的pooled-MSE/RMSE、MAE和每场命名风暴的描述值；重叠名称描述不可再次汇入总评分。

R²=1−SSE/sum((z−该评价集合均值)²)，在同一评价集合内比较；另报相对训练风暴均值基线的skill=1−SSE_model/SSE_B00，明确两者不同。逐过程结果近常数导致分母为零时置NA，不强制设0或1。不得用不同人口的R²上升证明误差改善。

预定配对比较：S02−G02（专用人口）；P00−G02（水平偏移）；P02−P00（曲率差异）；S03/S04−S02（形状）；S05−S02（交互模型）；S05−G05（树模型的人口效应）；S02−B01（阵风增量）。

### 8.2 区分“均值校准”与“事件区分”

每个过程报告预测/观测均值、残差均值、SD(预测)/SD(观测)、Pearson/Spearman相关及校准截距与斜率（回归观测z对预测z）。预测几乎常数时标明斜率不稳定/不可估。

精确分解SSE_j=sum((e−mean(e_j))²)+n_j·mean(e_j)²。后项显示过程平均偏差，前项显示去掉该偏差后仍有多少事件内误差。使用测试标签计算的过程偏移仅用于诊断，不能回写测试预测或作为可部署成绩；它也不是所有更复杂模型的性能上界。

至少画：按过程分面的共同尺度预测—观测图；观测与预测对阵风图；残差对预测及阵风图；各过程误差差值；带支持分布的候选阵风曲线。若只改善截距而相关/事件内误差未改善，结论应为校准改善。

### 8.3 不确定性与选择纪律

两个时间测试过程无法支持可靠的风暴总体95%区间；五个保护组也很少。以逐过程配对差、范围、删一过程敏感性为主，不使用事件级随机bootstrap制造精确推断。若提供五过程重抽样区间，必须标为条件于固定预测、极少群组的探索性描述，不作显著性门槛。

开发macro-MSE最低为点选型依据。相对差距≤1%的候选组成“近似并列”名单，优先数值可靠、构造简单者；1%仅是事先固定的选型简化规则，不是工程等效界值。E、R、R_C分别选，不要求统一赢家。并报告全部候选，不能在看到测试结果后更换入选模型。

工程价值用实际误差差值、尾部表现及用途解释；不预设R²必须达到0.5等阈值。若资源配置目标是风暴总受影响人数或总恢复负担，那是另一项涉及事件发生数量、重复客户和未发生事件的任务，不能靠汇总现有事件预测就宣称已解决。
