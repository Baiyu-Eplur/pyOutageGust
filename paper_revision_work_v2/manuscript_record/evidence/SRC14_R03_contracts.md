本文件记录已实现的代码规则。R01 原契约副本位于 frozen/contracts，保持原字节；本轮实现不等于正式 B1 已完成。

## 输入与入口

实际入口为 R03/cli.py → src/run_pipeline.py::run → producer.step0_build_sample → load_events。输入 manifest 的 run_id 必须为 R02_input_20260905，事件表版本列必须为 R02_20260905；manifest 与 parquet 的 SHA 均检查，不存在 H0 回退。当前事件总表 135,025 行，ID 唯一。

step2_build_folds 调用 global_date_folds，在定向对账阶段按主 E/R 候选并集一次生成日期映射；实际拟合入口读取这一指定 CSV，并检查映射 SHA 与上游成员 SHA。原 v9 和 R02 旧阻断入口均不修改、不导入；新增生产入口完成连接。研究期沿用 UTC [2021-04-01, 2024-04-01)，later 自 2023-09-30；不是业务时区真值声明。

## 共同折分、尾部与设计

基础候选 60,436 个事件、1,096 个 UTC 日期。日期按事件数降序、日期升序稳定排序，每次分给累计人数最少的折，并列取最小折号；共 5 折。人数为 12,098 / 12,085 / 12,085 / 12,085 / 12,083，日期数为 216 / 220 / 220 / 220 / 220。主/天气共用映射，不在天气子集重分。

主配置沿用 R01 明确的 all_valid：训练、评价均保留预定义有效目标；全样本描述拟合单列 all_valid_descriptive。备选 main_train_p99 只限制恢复训练：在取天气子集之前，以该折主恢复有效训练事件为参考，numpy.quantile(method='linear', q=.99)，保留 D <= 阈值；记录参考人数、阈值、保留人数和身份。E0 不按 D 截尾。测试集永不按测试 D 截尾。备选尚未运行，不因分数选择方案。

E0 = ln(1+C)，C = customers_v2_event_excl_reinterruptions；R0c = ln(D)，D = duration_B_full_span_hours。Duration (hours) 为 A 的兼容列，禁止作为恢复目标。

训练数据估计四天气及 R0c 的 ln(1+C) 均值/样本 SD（ddof=1）；只有这些列标准化。区域五列为 urban_binary、log_population、income_deprivation_rate、deprivation_gap_pct、morans_i，保留原尺度；人口已取自然对数。年份和月份分别为加性哑变量，各自最早类别作为基准；测试未知类别明确报错，不回退基准。不增加 LAD 固定效应。

天气控制保留降雨、气温、气压；阵风块 G = zG、zG²、zG×zPressure；恢复客户块 K = zK、zK²。E0 对照 control/G；R0c 对照 control/G/K/GK。同目标同人群所有块共用训练/评价资格、预处理、折分、事件等权；缺预测变量先拒绝不完整共同总体，不能各模型自行删行。设计列顺序和类别随模型归档；要求满列秩、n > k。

## 评分与模型身份

每个评价事件恰有一次相应折 OOF；检查 ID、目标、折号和 OOF 来源。pooled R² = 1 − SSE/SST，SST 围绕全部该评价集合的目标均值；同时保存 n/SSE/SST/尺度/事件身份。逐折独立计算同一定义；mean-fold 为五折不加权平均，任一折未定义则平均未定义。允许负 R²；n < 2 或 SST=0 则为 null 和明确状态。失败的拟合直接停止，不偷换分母后报告成功。

恢复增量为 R²(GK)−R²(K) 与 R²(GK)−R²(G)，另存相对 control 的各自增量。主和天气评价总体不同，只在人群内配对；不能把其差写成同一总体的检验。日分组仅为 B1 诊断，风暴过程依赖和不确定性仍待 V。

模型采用 JSON 归档：参数、列顺序、预处理、训练 ID/日期、训练规模、rank、condition number、run_id、输入版本、配置/代码身份；OOF 模型另存评价身份。存取后逐行预测完全一致。拟合与写入分函数；输出根须在修复工作根内且 run 目录不存在。缺指定版本产物就停止；绘图数据消费者不自行拟合、不读取旧 CSV。

E0 的拟合 log 值直接为 η，η=0 的输出为 0，不能再算 ln(1+expη)。R0c 同样使用 η 对照 ln(D)。同时保存 mean(η)、exp(meanη)、mean(expη)，不宣称为已校正的条件算术均值；E0 expη 对应 1+C 的指数拟合量。

最低点接口保存 β1/β2/β3、训练 gust/pressure 均值和 SD、固定物理气压、p1–p99 支持及失败原因。v*=μG−sG(β1+β3 zP)/(2β2)，要求正且非近零曲率、顶点在支持内。区间一律 null；不读历史 Bootstrap、不填旧区间。有效代数顶点不能说明稳定 U 形、工程阈值或机制。
